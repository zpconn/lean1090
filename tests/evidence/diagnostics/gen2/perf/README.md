# Gen2 native sampling evidence

This is one native `perf record -e cpu-clock:u -F 199 --call-graph dwarf,16384` pass over the complete corpus through the frozen headline worker, pinned to guest logical CPU 0. It is diagnostic sampling, not an ABAB benchmark or a throughput measurement. The worker's raw response is retained only to show protocol completion; do not use its instrumented duration as a performance result.

The capture runs the actual gen2 timed binary, SHA-256 `71c52eabb059fb6b80d71ee2b0950f85630a0b0a32ec4a9704f4fbf32701eded`, from commit `f05d8b1bd697269efdb2d73b045fdf50a481f969`. The helper verifies all 22 linked source/C/object/trace sets against `bench/runs/gen2/fresh-native-inputs.json`, every source against its committed blob, and all native hashes against `binary-built.json`. All captured input hashes match before/after. The diagnostic driver build finished before this pass; native diagnostic and Callgrind jobs were held until capture completion. Other agents could read evidence or prepare orchestration. This does not establish Windows host-wide isolation.

`run_perf_gen2.py` and `analyze_perf_gen2.py` adapt the retained gen1 helpers. The capture command, inputs, affinity, preserved binary path and raw-data hash are in `capture.json`. The preserved binary copy is for later symbol lookup and was not executed. Raw perf data remains `.cache/gen3-planning/perf-gen2/perf.data`; the campaign archiver retains it via its explicit `--perf-data` option. The helper does not rebuild any production code or alter the native image.

All 719 recorded samples parse. Both `report-self.txt` and `report-children.txt` explicitly report `# Total Lost Samples: 0` at line 4. Exactly 530 samples have the live `Impl.decode` frame; 189 others are excluded and separately classified. Unknown frames occur in 709 recorded stacks and 54 included leaf positions. Missing, inlined or tail-called frames may bias the visible subset; absence of the decoder frame does not prove a sample is preparation. The unresolved report substage remains explicit. The disjoint tables sum to 530; nested Rat/GMP/Parity/software-binary64/enclosure/table categories overlap and must not be added together.

Gen2 eagerly initializes its 13 immutable field-density tables during module startup before `main`. These initialization costs are outside the decode-visible subset when their actual stacks lack `Impl.decode`; they are not silently assigned to a decoder stage. The recording also contains input preparation, result consumption/destruction, runtime startup and possible unwind failures. Conditional shares among the 530 visible decoder stacks are not whole-decoder timing shares or proof of causal speedup. The full benchmark and the exhaustive Callgrind cost accounting are separate evidence.
