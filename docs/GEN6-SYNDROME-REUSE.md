# Generation 6: share a syndrome within one decode

The complete [gen5 diagnostic](GEN5-COST-BREAKDOWN.md) and independent review passed before this change. Frame/CRC is largest at 38.86% of 33,549,250,063 instructions. Its 287,418 syndrome calls comprise 172,432 report calls, 31,395 DF17 acceptance calls and 83,591 address-recovery calls. DF11 already shares the report's syndrome for its interrogator result. These are actual caller counts and diagnostic costs, not a predicted speedup.

Gen6 computes the syndrome once after decoding a frame and passes it to common pure acceptance/address/report helpers. Existing public entrypoints delegate to those same live helpers. This reuse is local to one message, with no mutable state or cache across messages or runs. Every field and acceptance result remains equal to the frozen reference for all inputs.

The earlier decoder could reject some invalid ADS-B frames before calculating any CRC. Computing the shared value before acceptance can add work on those rejected inputs; it does not change their result. No corpus key or special case is involved.
